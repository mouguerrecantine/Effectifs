# Effectifs

Suivi des effectifs de la cantine (repas et goûters des écoles) et de l'accueil de loisirs
(mercredis et vacances), avec bilans par année civile.

- Site : https://mouguerrecantine.github.io/Effectifs/
- Données et connexion : Firebase (Firestore + Authentication), protégées par `firestore.rules`.
- Aucune donnée n'est stockée dans ce dépôt public.

Mise en route, architecture et règles de calcul : voir [`CLAUDE.md`](CLAUDE.md).
